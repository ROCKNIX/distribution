# Backup & Privacy (Optional)

- For sensitive or private projects, use pre-commit hooks to automate backup of instruction files to a secure location.
- Add instruction and prompt files to `.git/info/exclude` to keep them private and untracked if needed.
- For public or open-source projects, assess privacy and backup needs based on project requirements.
